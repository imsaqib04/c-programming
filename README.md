# 📘 C Programming Exercises

This repository contains a **collection of C programming exercises and practice problems**.
The programs are organized into `assignments` and `practice` folders, covering topics from basic C syntax to **data structures**.

---

## 📂 Project Structure

### **Assignments**

* **assignment-1**

  * `q1.c` – Sum of two double-precision numbers
  * `q2.c` – Print alphabets (A–Z) with ASCII values
  * `q3.c` – Check if an integer is even or odd
  * `q4.c` – Factorial using loop
  * `q5.c` – Right-angled triangle pattern of numbers
  * `q6.c` – Multiply two numbers using repeated addition
  * `q7.c` – Swap two integers using a temporary variable
  * `q8.c` – Prime number check
  * `q9.c` – Leap year check
  * `q10.c` – Sum of digits of a number
  * `q11.c` – Repeatedly sum digits until a single digit
  * `q12.c` – Simple calculator using `switch`
  * `a.exe` – Compiled executable file
* **assignment-2**

  * `q1.c` – Reverse digits of an integer
  * `q2.c` – Generate Fibonacci series
* **assignment-3**

  * `q1.c` – Area of shapes (square, rectangle, circle, triangle) using `switch`
  * `q2.c` – Find largest & smallest in an array
  * `q3.c` – Store squares in array & print square of a given number
  * `q4.c` – Print a (2n-1) × (2n-1) matrix
* **assignment-4**

  * `q1.c` – Factorial using recursion
  * `q2.c` – Fibonacci using recursion
  * `q3.c` – Linear search
  * `q4.c` – Binary search using recursion
  * `q5.c` – Integer stack (push, pop, peek, display)
  * `q6.c` – Integer queue (enqueue, dequeue, display)
  * `q7.c` – Character stack
* **assignment-5**

  * `q1.c` – Doubly linked list (insert, delete, search, reverse, traverse)

### **Practice Programs**

* `arr_q1.c` – Merge two sorted arrays into a third

* `static_fun.c` – Static variable inside a function

## ⚙️ How to Compile & Run

You can compile using **GCC** or any C compiler.

Example:

```sh
# Compile
gcc assignments/assignment-1/q3.c -o q3

# Run
./q3
```

💡 **Note:** Each program is independent. Compile & run files individually.
